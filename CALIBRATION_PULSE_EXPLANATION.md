# Calibration Pulse - How It Actually Works

## Summary
The calibration pulse is **NOT generated by the frontend**. It comes from the ESP32 watch and is embedded in the waveform data stream.

## Correct Flow

### 1. Trigger (Frontend → Backend → ESP32)
- **Frontend:** Opens ECG viewer with `triggerCalibration=true` in WebSocket subscription
- **Backend:** [websocket.py:96-120](../hospital-backend/app/api/v1/websocket.py#L96-L120) receives subscription, sends MQTT `calibrate` command
- **ESP32:** [esp32_hospital_watch_complete.ino:752](../esp32_hospital_watch_complete/esp32_hospital_watch_complete.ino#L752) receives command, calls `handleCalibrationCommand()`

### 2. Pulse Generation (ESP32 Only)
- **ESP32:** [esp32_hospital_watch_complete.ino:909](../esp32_hospital_watch_complete/esp32_hospital_watch_complete.ino#L909) calls `simulator.startCalibrationPulse()`
- **Simulator:** [PhysiologicalSimulator.cpp:249-252](../esp32_hospital_watch_complete/PhysiologicalSimulator.cpp#L249-L252) sets `calibrationActive = true`
- **Waveform Generation:** [PhysiologicalSimulator.cpp:274-292](../esp32_hospital_watch_complete/PhysiologicalSimulator.cpp#L274-L292)
  - Checks if calibration is active
  - If yes, generates calibration pulse instead of normal ECG:
    - **0-200ms:** Flat baseline (0mV) - ADC 8388608
    - **200-400ms:** 1mV square pulse - ADC 8388608 + 100000
    - **400-600ms:** Flat baseline (0mV) - ADC 8388608
  - After 600ms, `calibrationActive` becomes false
  - Returns to normal ECG generation

### 3. Pulse Transmission (ESP32 → Backend → Frontend)
- **ESP32:** Streams waveforms every 100ms via MQTT `hospital/devices/{deviceId}/stream`
- **Backend:** [mqtt_service.py](../hospital-backend/app/services/mqtt_service.py) forwards to WebSocket
- **Frontend:** [useECGViewer.ts](../hospital-display-app/src/hooks/useECGViewer.ts) receives waveform data and renders it

## What the Frontend Should Do
- **Display the waveform data as-is**
- **NO frontend-generated calibration pulse**
- If calibration pulse appears in the data (during that 600ms window), it will automatically be visible

## The `showCalibration` State (Currently Unused)
- [useECGViewer.ts:26](../hospital-display-app/src/hooks/useECGViewer.ts#L26) has `showCalibration` state
- [useECGViewer.ts:324](../hospital-display-app/src/hooks/useECGViewer.ts#L324) returns it to components
- **BUT:** No canvas component actually uses this state
- **Conclusion:** This state is vestigial and should probably be removed

## Medical Standard vs. Our Implementation

### Medical Standard (What User Expected)
- Calibration pulse displayed **permanently** at the start of every ECG strip
- Standard format: 1mV (10mm) square wave for 0.2s (5mm width at 25mm/s)
- Purpose: Visual reference for amplitude calibration

### Our Implementation (What We Actually Have)
- Calibration pulse generated **on-demand** for 600ms when commanded
- After 600ms, it's gone and replaced with normal ECG
- Not permanently visible

## Options Going Forward

### Option 1: Keep It As-Is (On-Demand Only)
- Calibration pulse only shown when explicitly triggered via MQTT command
- User can manually trigger it by refreshing ECG viewer (since `triggerCalibration=true` in subscription)
- **Pro:** Matches current behavior
- **Con:** Not medical standard

### Option 2: Make Calibration Permanent (Medical Standard)
Would require changes to:

1. **ESP32 Firmware:**
   - Modify [PhysiologicalSimulator.cpp](../esp32_hospital_watch_complete/PhysiologicalSimulator.cpp) to generate calibration pulse at the START of every waveform stream packet
   - OR generate calibration once and prepend to every waveform buffer

2. **Frontend:**
   - Modify [ECGWaveformCanvas.tsx](../hospital-display-app/src/components/ECGViewer/ECGWaveformCanvas.tsx) to render calibration pulse overlay at fixed position
   - Draw 1mV (10mm) square wave at left edge before rendering actual waveform data

## What User Probably Wants
Based on "i dont want calibration thing to go away", the user likely wants:

**Option 2 - Medical Standard Permanent Calibration Pulse**

This would show a 1mV square wave permanently at the left edge of every ECG strip for visual amplitude reference.
