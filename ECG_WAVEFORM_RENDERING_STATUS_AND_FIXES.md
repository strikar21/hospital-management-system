### Issue #2: Calibration Pulse Source (ARCHITECTURAL)

**User Question:** "normally woudl the calibration happen from watch or on screen?"

**Current Implementation:**
- Frontend software generates calibration pulse in `ECGViewerContainer.tsx` (lines 51-73)
- Adds 1mV × 200ms pulse + 200ms tail to data buffer on component mount
- This is **NOT** how real ECG machines work

**Correct Medical Practice:**
- Real ECG machines generate calibration pulse from **HARDWARE**
- Pulse is physically generated by the device
- Verifies entire signal chain (sensors → ADC → transmission → display)
- Frontend calibration only tests display rendering, not signal accuracy

**Why This Matters:**
- Software calibration doesn't validate sensor/ADC/transmission path
- Cannot detect hardware issues (bad electrodes, ADC errors, signal loss)
- Medical professionals expect hardware-generated calibration
- Required for regulatory compliance (FDA, ISO 13485)

**Recommended Fix:**
