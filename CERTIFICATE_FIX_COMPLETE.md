## Troubleshooting

### If Backend MQTT Connection Fails
1. Check Mosquitto is running: `docker ps | grep mosquitto`
2. Restart Mosquitto: `docker restart hospital_mosquitto`
3. Check backend logs for SSL errors
4. Verify certificates exist:
   - `mosquitto/certs/hospital_ca.crt`
   - `mosquitto/certs/server.crt`
   - `mosquitto/certs/backend.crt`
5. Validate certificate chain:
   ```bash
   openssl verify -CAfile mosquitto/certs/hospital_ca.crt mosquitto/certs/backend.crt
   ```

### If ESP32 MQTT Connection Fails
1. Verify SPIFFS upload completed successfully
2. Check ESP32 serial for certificate loading errors
3. Verify CA certificate exists on ESP32: `/spiffs/ca.crt`
4. Check device certificate was received during provisioning
5. Ensure ESP32 firmware matches updated organizational details
